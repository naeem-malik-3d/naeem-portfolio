Live n8n Automation

AI Lead Triage Automation

An end-to-end workflow that takes a raw customer inquiry, classifies it with Claude, and routes it — with real branching logic and no manual steps.
Try the live form

How it works

1
Form Trigger n8n Form
A customer submits a raw inquiry through a hosted form — no email or manual entry needed. This fires the workflow instantly.
2
Claude Classification Anthropic API
The raw text is sent to Claude with a structured prompt. Claude returns category, urgency, recommended routing, and a ready-to-send reply — as JSON.
3
Parse Response Code node
A small JavaScript step extracts Claude's JSON output into clean, usable fields for the rest of the workflow.
4
Urgency Branch IF condition
The workflow checks urgency and branches — high-priority leads can be routed differently from routine ones, without any manual triage.
5
Log to Sheet Google Sheets
Every classified lead is appended to a tracking sheet — category, urgency, routing, and draft reply — acting as a lightweight CRM.

Why this matters

This mirrors a real automation a business would use to stop manually reading and sorting every incoming inquiry — the same pattern used for lead intake, support triage, and CRM automation.

Built and tested end-to-end in n8n, using the Anthropic API for the reasoning step. Try the live form above with your own inquiry to see it classify in real time.
